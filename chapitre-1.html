    1. De la donnée à la connaissance

    Définitions
    • Donnée : une valeur brute, sans contexte. Exemple : 380.
    • Information : une donnée placée dans son contexte. Exemple : « une imprimante coûte 380 DT ».
    • Connaissance : ce qu'on comprend en analysant plusieurs informations. Exemple : « les ventes de mobilier sont élevées, il faut garder du stock ».
    NiveauExemple dans une boutique
    DonnéeSousse, 3, 380
    InformationÀ Sousse, on a vendu 3 imprimantes à 380 DT l'unité.
    ConnaissanceUn tableau de synthèse par région aide à décider où livrer en premier.

    Attention au séparateur

    Ce fichier utilise le point-virgule. Il faut l'indiquer à pandas avec sep=";". Sinon, tout le contenu d'une ligne reste dans une seule colonne.

    3. Pourquoi utiliser Python et pandas ?

    • Les mêmes étapes se rejouent sur un nouveau fichier en un clic.
    • Le programme garde la trace de tout ce qui a été fait.
    • Le travail reste possible quand le fichier devient grand.

    Deux bibliothèques servent dans ce cours : pandas pour organiser et calculer, matplotlib pour dessiner des graphiques.

    4. Installer et importer pandas

    Dans une console (invite de commandes), on tape :

    pip install pandas matplotlib openpyxl

    openpyxl permet à pandas de lire les fichiers xlsx. Dans le programme, on importe ensuite :

    import pandas
import matplotlib.pyplot as plt
    Alias

    Beaucoup de programmes écrivent import pandas as pd et utilisent pd. à la place de pandas.. Dans ce cours, on écrit pandas. en entier, comme dans les aides pédagogiques. Les deux écritures sont équivalentes.

    1. Importer pandas.

    DataFrame

    Un DataFrame est un tableau : des lignes, des colonnes et un index (le numéro de chaque ligne, à partir de 0). Il ressemble à une feuille de calcul.

    Votre écran peut différer légèrement

    Les résultats de ce site viennent de pandas 3. Avec une version plus ancienne, certaines lignes de info() s'écrivent autrement (object au lieu de str). Les données restent les mêmes.

    Niveau 2 – entraînementExercice 2

    Classer chaque élément : donnée, information ou connaissance. (a) 1450 – (b) « Un ordinateur portable coûte 1450 DT. » – (c) « Les produits chers se vendent peu, il faut proposer un paiement échelonné. »

    Niveau 3 – problèmeExercice 3

    Lire data/ventes.csv sans préciser le séparateur. Afficher les dimensions. Expliquer le problème, puis le corriger.

    Voir la correction
    import pandas

mauvais = pandas.read_csv("data/ventes.csv")
print(mauvais.shape)
bon = pandas.read_csv("data/ventes.csv", sep=";")
print(bon.shape)
    (24, 1) (24, 6)

    Sans séparateur, pandas cherche la virgule. Il ne la trouve pas : tout reste dans une seule colonne. Avec sep=";", on retrouve les 6 colonnes.

    Auto-évaluation

    Quelle valeur est une donnée ?

    Une valeur seule, sans contexte, est une donnée.

    Quelle fonction lit un fichier csv ?

    read_csv lit un csv.

    Quel paramètre indique le séparateur d'un csv ?

    On écrit sep=";".

    Que contient df.shape ?

    shape renvoie un couple (lignes, colonnes).

    À partir de quel numéro l'index d'un DataFrame commence-t-il ?

    L'index commence à 0, comme les listes Python.
