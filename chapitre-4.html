    Chapitre 4 – Modifier, ajouter et nettoyer les données

    Durée indicative : 3 séances

    Objectifs
    • Modifier une cellule, une ligne ; ajouter une ligne et une colonne calculée.
    • Supprimer les doublons et les valeurs nulles.
    • Choisir la bonne méthode de nettoyage.
    Prérequis
    • Chapitres 2 et 3.
    import pandas

df = pandas.read_csv("data/ventes.csv", sep=";")
print(df.shape)
    (24, 6)

    1. Modifier des données

    Modifier une cellule

    print(df.loc[0, "Quantite"])
df.loc[0, "Quantite"] = 4
print(df.loc[0, "Quantite"])
    3 4

    Ici, la modification change directement df. Ce n'est pas le cas de drop ou rename.

    Ajouter une ligne

    On donne un index nouveau (ici 24) et la liste des valeurs, dans l'ordre des colonnes.

    df.loc[24] = [25, "Agrafeuse", "Papeterie", "Tunis", 7, 8]
print(df.tail(2))
print(df.shape)
    Id Produit Categorie Region Quantite PrixUnitaire 23 24 Chaise Mobilier Sousse 1 150 24 25 Agrafeuse Papeterie Tunis 7 8 (25, 6)
    Index existant

    Si l'index existe déjà, la ligne est remplacée. Vérifier l'index avant d'écrire.

    Ajouter une colonne calculée

    df["Montant"] = df["Quantite"] * df["PrixUnitaire"]
print(df[["Produit", "Quantite", "PrixUnitaire", "Montant"]].head())
    Produit Quantite PrixUnitaire Montant 0 Imprimante 4 380 1520 1 Chaise 1 150 150 2 Armoire 5 560 2800 3 Classeur 10 6 60 4 Bureau 5 420 2100

    Le calcul se fait sur toute la colonne d'un seul coup, ligne par ligne.

    2. Nettoyer les données

    Le fichier ventes_brutes.csv contient des erreurs volontaires : lignes en double, valeurs vides et une colonne entièrement vide.

    brut = pandas.read_csv("data/ventes_brutes.csv", sep=";")
print(brut.shape)
brut.info()
    (26, 7) <class 'pandas.DataFrame'> RangeIndex: 26 entries, 0 to 25 Data columns (total 7 columns): # Column Non-Null Count Dtype --- ------ -------------- ----- 0 Id 26 non-null int64 1 Produit 26 non-null str 2 Categorie 26 non-null str 3 Region 25 non-null str 4 Quantite 25 non-null float64 5 PrixUnitaire 25 non-null float64 6 Commentaire 0 non-null float64 dtypes: float64(3), int64(1), str(3) memory usage: 1.6 KB

    La colonne Commentaire n'a aucune valeur. Les colonnes Region, Quantite et PrixUnitaire ont chacune des cases vides.

    Étape 1 : supprimer la colonne inutile

    brut = brut.drop(columns=["Commentaire"])
print(brut.shape)
    (26, 6)

    Étape 2 : supprimer les doublons

    brut = brut.drop_duplicates()
print(brut.shape)
    (24, 6)

    Étape 3 : supprimer les lignes contenant des valeurs nulles

    brut = brut.dropna()
print(brut.shape)
    (21, 6)
    dropna(axis=1) : attention

    dropna() supprime les lignes qui ont au moins une case vide. dropna(axis=1) supprime les colonnes qui ont au moins une case vide. Voyons ce que cela donne sur le fichier d'origine :

    brut2 = pandas.read_csv("data/ventes_brutes.csv", sep=";")
print(brut2.dropna(axis=1).columns)
    Index(['Id', 'Produit', 'Categorie'], dtype='str')

    On perd trois colonnes utiles ! Pour une colonne entièrement vide, il vaut mieux la supprimer avec drop(columns=[...]).

    À retenir
    • df.loc[n, "Col"] = valeur modifie une cellule. df.loc[n] = [liste] ajoute ou remplace une ligne.
    • df["Nouvelle"] = formule ajoute une colonne calculée.
    • Ordre conseillé du nettoyage : colonnes inutiles, doublons, valeurs nulles.
    • drop_duplicates() et dropna() renvoient un nouveau DataFrame : on réaffecte.
    ActionSyntaxe
    Modifier une celluledf.loc[n, "Col"] = valeur
    Ajouter/modifier une lignedf.loc[n] = [v1, v2, …]
    Ajouter une colonnedf["Col"] = formule
    Supprimer les doublonsdf.drop_duplicates()
    Supprimer les lignes avec valeur nulledf.dropna()
    Supprimer les colonnes avec valeur nulledf.dropna(axis=1)
