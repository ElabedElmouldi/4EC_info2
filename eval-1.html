    Exercice 2 – Lire et afficher (6 points)

    Niveau 2Question 2.1 (1.5 pts)

    Exercice 3 – Transformer le DataFrame (6 points)

    Niveau 2Question 3.1 (2 pts)

    Renommer Montant en MontantDT et afficher les noms des colonnes.

    Voir le corrigé
    import pandas

cmd = pandas.read_csv("data/commandes.csv", sep=";")
cmd = cmd.rename(columns={"Montant": "MontantDT"})
print(cmd.columns)
    Index(['Id', 'Client', 'Ville', 'MontantDT', 'Statut'], dtype='str')

    Barème détaillé : rename 1 ; réaffectation 0,5 ; affichage 0,5.

    Niveau 2Question 3.2 (2 pts)

    Supprimer la colonne Id, puis les lignes d'index 0 à 4 (consécutives). Afficher les dimensions.

    Voir le corrigé
    import pandas

cmd = pandas.read_csv("data/commandes.csv", sep=";")
cmd = cmd.drop(columns=["Id"])
cmd = cmd.drop(cmd.index[0:5])
print(cmd.shape)
    (15, 4)

    Barème détaillé : colonne 1 ; lignes consécutives 1.

    Niveau 3Question 3.3 (2 pts)

    Un élève écrit cmd.rename(columns={"Ville": "Lieu"}) puis affiche cmd.columns : la colonne s'appelle toujours Ville. Expliquer pourquoi et corriger.

    Voir le corrigé

    rename renvoie un nouveau DataFrame et laisse cmd inchangé. Correction : cmd = cmd.rename(columns={"Ville": "Lieu"}).

    Barème détaillé : explication 1 ; correction 1.

    Exercice 4 – Problème (4 points)

    Niveau 3Question 4 (4 pts)

    Sans écrire le numéro de la dernière ligne, afficher le nom du client de la dernière commande, puis les 2 dernières lignes du fichier.

    Voir le corrigé
    import pandas

cmd = pandas.read_csv("data/commandes.csv", sep=";")
derniere = cmd.shape[0] - 1
print(cmd.loc[derniere, "Client"])
print(cmd.tail(2))
    Basma Id Client Ville Montant Statut 18 19 Chokri Tunis 410 En cours 19 20 Basma Sousse 360 Livrée

    Le programme reste juste si le nombre de commandes change.

    Barème détaillé : calcul de l'index 1,5 ; cellule 1 ; tail 1 ; programme complet 0,5.
