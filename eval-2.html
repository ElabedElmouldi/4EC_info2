    Niveau 2Question 2.2 (2.5 pts)

    L'élève d'index 0 a eu une erreur de saisie en Maths : la note correcte est 15. Corriger la note, puis recalculer Moyenne et afficher la ligne 0.

    Voir le corrigé
    import pandas

notes = pandas.read_csv("data/notes.csv", sep=",")
notes["Moyenne"] = (notes["Maths"] + notes["Gestion"] + notes["Informatique"] + notes["Economie"]) / 4
notes.loc[0, "Maths"] = 15
notes["Moyenne"] = (notes["Maths"] + notes["Gestion"] + notes["Informatique"] + notes["Economie"]) / 4
print(notes.loc[0])
    Eleve Sami Classe 4Eco1 Maths 15 Gestion 14 Informatique 15 Economie 7 Moyenne 12.75 Name: 0, dtype: object

    Barème détaillé : modification 1 ; recalcul 1 ; affichage 0,5.

    Exercice 4 – Problème (6 points)

    Niveau 2Question 4.1 (2 pts)

    Classer les élèves par moyenne décroissante. Afficher le nom et la moyenne des 3 meilleurs.

    Voir le corrigé
    import pandas

notes = pandas.read_csv("data/notes.csv", sep=",")
notes["Moyenne"] = (notes["Maths"] + notes["Gestion"] + notes["Informatique"] + notes["Economie"]) / 4
classement = notes.sort_values(by=["Moyenne"], ascending=[False])
print(classement[["Eleve", "Moyenne"]].head(3))
    Eleve Moyenne 19 Nesrine 15.50 2 Walid 15.25 7 Boutheina 15.25

    Barème détaillé : tri 1 ; sélection des colonnes et head 1.

    Niveau 3Question 4.2 (2 pts)

    Combien d'élèves ont une moyenne supérieure ou égale à 10 ?

    Voir le corrigé
    import pandas

notes = pandas.read_csv("data/notes.csv", sep=",")
notes["Moyenne"] = (notes["Maths"] + notes["Gestion"] + notes["Informatique"] + notes["Economie"]) / 4
admis = notes[notes["Moyenne"] >= 10]

    Niveau 3Question 4.3 (2 pts)

    Quelle classe a la meilleure moyenne générale ? Justifier par un calcul.

    Voir le corrigé
    import pandas

notes = pandas.read_csv("data/notes.csv", sep=",")
notes["Moyenne"] = (notes["Maths"] + notes["Gestion"] + notes["Informatique"] + notes["Economie"]) / 4
print(notes.groupby(["Classe"])["Moyenne"].mean())
    Classe 4Eco1 12.250 4Eco2 12.725 Name: Moyenne, dtype: float64

    La meilleure classe est celle dont la valeur affichée est la plus grande.

    Barème détaillé : groupby 1 ; conclusion lue dans le résultat 1.
