    Chapitre 3 – Afficher les données d'un DataFrame

    Durée indicative : 2 séances

    Objectifs
    • Afficher une colonne, plusieurs colonnes, une ligne, une cellule.
    • Afficher les premières et les dernières lignes.
    • Afficher une plage de lignes ou des lignes non consécutives.
    Prérequis
    • Chapitres 1 et 2.
    • Listes et découpage [a:b] en Python.

    Dans tout le chapitre, on travaille sur le DataFrame df lu depuis data/ventes.csv.

    import pandas

df = pandas.read_csv("data/ventes.csv", sep=";")
print(df.head())
    Id Produit Categorie Region Quantite PrixUnitaire 0 1 Imprimante Informatique Sousse 3 380 1 2 Chaise Mobilier Tunis 1 150 2 3 Armoire Mobilier Sousse 5 560 3 4 Classeur Papeterie Sousse 10 6 4 5 Bureau Mobilier Sfax 5 420

    1. Afficher des colonnes

    Une colonne

    print(df["Region"].head())
    0 Sousse 1 Tunis 2 Sousse 3 Sousse 4 Sfax Name: Region, dtype: str

    Plusieurs colonnes

    On donne une liste de noms : il y a donc deux paires de crochets.

    print(df[["Produit", "Quantite"]].head())
    Produit Quantite 0 Imprimante 3 1 Chaise 1 2 Armoire 5 3 Classeur 10 4 Bureau 5

    Une colonne, entre deux positions

    print(df["Produit"][2:5])
    2 Armoire 3 Classeur 4 Bureau Name: Produit, dtype: str
    Bornes

    Ici, [2:5] affiche les positions 2, 3 et 4. La dernière position (5) est exclue.

    2. Afficher des lignes

    Une ligne : loc

    print(df.loc[3])
    Id 4 Produit Classeur Categorie Papeterie Region Sousse Quantite 10 PrixUnitaire 6 Name: 3, dtype: object

    Les n premières et les n dernières lignes

    print(df.head(3))
print(df.tail(3))
    Id Produit Categorie Region Quantite PrixUnitaire 0 1 Imprimante Informatique Sousse 3 380 1 2 Chaise Mobilier Tunis 1 150 2 3 Armoire Mobilier Sousse 5 560 Id Produit Categorie Region Quantite PrixUnitaire 21 22 Chaise Mobilier Sfax 3 150 22 23 Armoire Mobilier Sousse 4 560 23 24 Chaise Mobilier Sousse 1 150

    Une plage de lignes

    print(df.loc[2:4])
    Id Produit Categorie Region Quantite PrixUnitaire 2 3 Armoire Mobilier Sousse 5 560 3 4 Classeur Papeterie Sousse 10 6 4 5 Bureau Mobilier Sfax 5 420
    loc inclut la borne finale

    Avec loc, 2:4 affiche les lignes 2, 3 et 4. C'est différent de [2:5] sur une colonne. Cette différence est une source d'erreurs : la retenir.

    Des lignes non consécutives

    On donne une liste d'index : deux paires de crochets.

    print(df.loc[[0, 8, 16]])
    Id Produit Categorie Region Quantite PrixUnitaire 0 1 Imprimante Informatique Sousse 3 380 8 9 Bureau Mobilier Tunis 3 420 16 17 Stylo Papeterie Sfax 6 1

    3. Afficher une cellule

    print(df.loc[3, "Produit"])
    Classeur
    À retenir
    • df["Col"] : une colonne. df[["A", "B"]] : plusieurs colonnes.
    • df.loc[n] : une ligne. df.loc[a:b] : de a à b inclus.
    • head(n) et tail(n) : début et fin.
    • df.loc[ligne, "Col"] : une cellule.
    Je veux afficher…J'écris…
    une colonnedf["Col"]
    plusieurs colonnesdf[["A", "B"]]
    une lignedf.loc[3]
    les lignes 2 à 4df.loc[2:4]
    les lignes 0, 8 et 16df.loc[[0, 8, 16]]
    une celluledf.loc[3, "Produit"]

    Niveau 3 – problèmeExercice 3

    Lire data/employes.xlsx (feuille Employes). Afficher le nom du premier et du dernier employé, sans écrire le numéro de la dernière ligne « à la main ».

    Voir la correction
    import pandas

emp = pandas.read_excel("data/employes.xlsx", "Employes")
derniere = emp.shape[0] - 1
print(emp.loc[0, "Nom"])
print(emp.loc[derniere, "Nom"])
    Amal Oussama

    emp.shape[0] est le nombre de lignes. L'index de la dernière ligne vaut ce nombre moins 1. Le programme reste correct si le fichier change de taille.
