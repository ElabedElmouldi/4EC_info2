    Niveau 3Question 3.3 (1.5 pts)

    Afficher les 3 plus grosses ventes (produit, région, montant).

    import pandas

brut = pandas.read_csv("data/ventes_brutes.csv", sep=";")

    Niveau 3Question 4.3 (2 pts)

    Représenter par des barres le solde des 6 premiers mois. Dire quel graphique convient le mieux pour suivre une évolution, et pourquoi.

    Voir le corrigé
    import pandas
import matplotlib.pyplot as plt

budget = pandas.read_csv("data/budget_mensuel.csv", sep=";")
budget["Solde"] = budget["Recettes"] - budget["Depenses"]
budget.head(6).plot.bar(x="Mois", y="Solde", title="Solde du premier semestre (DT)", color="seagreen", rot=30)
plt.show()

    Pour suivre une évolution dans le temps, la courbe convient mieux : elle montre la tendance d'un mois à l'autre.

    Barème détaillé : graphique 1 ; justification 1.
